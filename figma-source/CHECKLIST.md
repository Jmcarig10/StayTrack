# StayTrack route coverage checklist

Every route in `routes/web.php` (65 total) mapped to its Figma screen.
Frames live on the 5 pages generated by the plugin:

- **01 · Landing & Auth** — 10 frames
- **02 · Admin** — 25 frames
- **03 · Tenant** — 5 frames
- **04 · Components** — design-system reference frame
- **05 · Prototype Flows** — route-flow diagrams

Legend:
- **Action** = POST/PUT/PATCH/DELETE route; its output state is represented by the frames listed.
- **Verified** = ✔ plugin builds the frame without errors (checked in mock run); tick it again by eye after running in Figma.
- `(callbacks, asset serving)` = no visual page of its own; behavior is covered by the neighbor frames noted.

## How to run the verification

1. Import `figma-source/manifest.json` and run **StayTrack UI Source** (Plugins → Development).
2. Confirm the 5 pages and the 44 frames above appear (counts: 10 / 25 / 5 / 1 / 3).
3. Walk each row: open the figma frame, compare to the live site `http://127.0.0.1:8000`, mark **Verified** ✔.

Notes:
- Maintenance currently has no records in the live DB — the plugin intentionally shows 3 sample requests to demonstrate the list/detail designs, plus an empty-state variant frame.
- All create/edit screens share the same form scaffolds, so `edit` routes reuse the paired `create` frame (noted above).
